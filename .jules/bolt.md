## 2024-05-18 - [React Unmounting Anti-Pattern]
**Learning:** Defining functional components (like `CartContent`) entirely inside the render scope of a parent functional component (like `CashierClient`) is a fatal performance anti-pattern. React treats the nested function as a completely new reference on every single re-render of the parent. This forces a complete DOM teardown and remount, destroying local state and causing immense UI lag, especially in state-heavy applications like POS systems.
**Action:** Always verify that functional components are declared at the top module level. If they require parent scope variables, pass them explicitly as props. Use `React.memo` for the extracted component and `React.useCallback` for functions passed down to prevent unnecessary re-renders.
